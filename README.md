# รู้หนังสือไทย

เว็บแอปส่งเสริมการรู้หนังสือไทย: พยัญชนะ สระ วรรณยุกต์ ผสมคำ คำศัพท์ ฝึกอ่านประโยค และแบบทดสอบ มีภาพประกอบและเสียงอ่าน

สร้างสรรค์ โดย นายวนศาสตร์ วัฒนาสกุลลี

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าผู้เรียน |
| `admin.html` | ห้องครู สำหรับอัดเสียงหรืออัปโหลดไฟล์เสียงคนอ่านจริง |
| `config.js` | ใส่ค่า firebaseConfig ของโปรเจกต์ Firebase |
| `firestore.rules` | กฎความปลอดภัยของ Firestore (คัดลอกไปวางใน Firebase Console) |
| `audio/` | เสียงสังเคราะห์ที่มากับแอป (ใช้เมื่อครูยังไม่ได้อัดเสียง) |
| `img/` | ภาพประกอบ |

## ลำดับการเล่นเสียงในหน้าผู้เรียน

1. เสียงที่ครูอัดหรืออัปโหลดไว้ในห้องครู (เก็บใน Firebase Firestore และจำไว้ในเครื่องผู้เรียน ครั้งต่อไปเล่นได้ทันที)
2. ถ้าคำนั้นยังไม่มีเสียงคน จะใช้เสียงสังเคราะห์ที่มากับแอป

## ขั้นที่ 1: ขึ้นเว็บด้วย GitHub Pages

1. เข้า GitHub แล้วกด **New repository** ตั้งชื่อ เช่น `thai-literacy` เลือก **Public**
2. กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้นไป แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages** เลือก Branch: `main` / `(root)` แล้วกด **Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อบัญชี.github.io/thai-literacy/`
   - ห้องครู: `https://ชื่อบัญชี.github.io/thai-literacy/admin.html`

ถึงขั้นนี้แอปใช้งานได้แล้วด้วยเสียงสังเคราะห์ ถ้าต้องการเสียงคนอ่านจริง ทำขั้นที่ 2 ต่อ

## ขั้นที่ 2: เปิดระบบเก็บเสียงคน (Firebase โปรเจกต์ใหม่ แพ็กเกจฟรี Spark)

### 2.1 สร้างโปรเจกต์
1. เข้า https://console.firebase.google.com กด **Create a project / เพิ่มโปรเจกต์**
2. ตั้งชื่อ เช่น `thai-literacy` (Google Analytics ปิดได้) แล้วกดสร้าง

### 2.2 เปิด Firestore
1. เมนูซ้าย **Build → Firestore Database → Create database**
2. เลือกตำแหน่ง `asia-southeast1 (Singapore)` (ใกล้ไทย เร็วกว่า)
3. เลือก **Start in production mode** แล้วกด **Create**

### 2.3 เอาค่า config มาใส่ใน `config.js`
1. กดรูปเฟือง **Project settings** → เลื่อนลงไปที่ **Your apps** → กดไอคอน **</>** (Web)
2. ตั้งชื่อแอป เช่น `thai-literacy-web` (ไม่ต้องติ๊ก Hosting) แล้วกด **Register app**
3. จะเห็นโค้ด `const firebaseConfig = { apiKey: "...", ... }` ให้คัดลอกค่าในวงเล็บปีกกา
4. เปิดไฟล์ `config.js` แล้ววางแทนค่าว่าง เช่น

   ```js
   window.TL_FIREBASE = {
     apiKey: "AIza...",
     authDomain: "thai-literacy-xxxx.firebaseapp.com",
     projectId: "thai-literacy-xxxx",
     storageBucket: "thai-literacy-xxxx.firebasestorage.app",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcd"
   };
   ```

   ค่าเหล่านี้เปิดเผยได้ ความปลอดภัยมาจากกฎในขั้น 2.5

### 2.4 สร้างบัญชีครู
1. เมนูซ้าย **Build → Authentication → Get started**
2. แท็บ **Sign-in method** เลือก **Email/Password** → เปิด **Enable** → Save
3. แท็บ **Users** กด **Add user** ใส่อีเมลและรหัสผ่านของครู
4. แท็บ **Settings → Authorized domains** กด **Add domain** ใส่ `ชื่อบัญชี.github.io`

### 2.5 ตั้งกฎความปลอดภัย
1. ไปที่ **Firestore Database → แท็บ Rules**
2. ลบของเดิม แล้ววางเนื้อหาจากไฟล์ `firestore.rules`
3. แก้ `'ใส่อีเมลครูตรงนี้@gmail.com'` เป็นอีเมลครูที่สร้างในขั้น 2.4 (หลายคนใส่ได้ เช่น `['a@gmail.com', 'b@gmail.com']`)
4. กด **Publish**

### 2.6 อัปไฟล์ `config.js` ที่แก้แล้วขึ้น GitHub
แก้ไฟล์ `config.js` ใน GitHub (กดดินสอ) วางค่าจากขั้น 2.3 แล้วกด **Commit changes** รอ 1–2 นาที

## วิธีใช้ห้องครู

1. เปิด `admin.html` ใส่อีเมลและรหัสผ่านครูที่สร้างไว้ในขั้น 2.4 แล้วกด **เข้าสู่ระบบ**
2. เลือกหมวด หรือพิมพ์ค้นหาคำ
3. แต่ละรายการมีปุ่ม
   - **ฟัง** ฟังเสียงที่ใช้อยู่ตอนนี้
   - **อัดเสียง** อัดจากไมโครโฟน (กด **หยุดอัด** เมื่ออ่านจบ อัดได้นานสุด 15 วินาที) เบราว์เซอร์จะถามสิทธิ์ใช้ไมโครโฟนครั้งแรก ให้กดอนุญาต
   - **อัปโหลดไฟล์** เลือกไฟล์เสียง เช่น .mp3 .m4a .wav ขนาดไม่เกิน 700 KB (ประมาณ 15–30 วินาที)
   - **บันทึก** ส่งเสียงขึ้นระบบ ผู้เรียนจะได้ยินเสียงนี้ทันทีเมื่อเปิดหน้าใหม่
   - **ลบเสียงคน** กลับไปใช้เสียงสังเคราะห์
4. อ่านให้ตรงกับบรรทัด "อ่านว่า" เช่น พยัญชนะ ก ให้อ่านว่า "กอ ไก่"

## หมายเหตุ

- ส่วน "ผสมคำ" มีคำที่ผสมได้หลายพันแบบ จึงใช้เสียงสังเคราะห์เท่านั้น
- แพ็กเกจฟรีของ Firestore อ่านข้อมูลได้วันละ 50,000 ครั้ง เครื่องผู้เรียนจะโหลดเสียงแต่ละคำจาก Firebase ครั้งเดียวแล้วจำไว้ในเครื่อง จึงใช้โควตาน้อย
- ไม่ต้องใช้ Firebase Storage (ซึ่งต้องผูกบัตรเครดิต) เพราะเก็บเสียงไว้ใน Firestore โดยตรง
- เสียงสังเคราะห์สร้างจากโมเดล MMS ของ Meta ภาพประกอบส่วนใหญ่จาก Twemoji (CC BY 4.0)
